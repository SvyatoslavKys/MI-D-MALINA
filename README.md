# Miód Malina — версия на React

Это основная версия сайта на React. Старые HTML/CSS/SCSS/JS-файлы удалены, а приложение
теперь запускается прямо из корня проекта. Для работы нужен Node.js 20.19+ или 22.12+.

## Запуск

В терминале, находясь в папке `MI-D-MALINA`, установите зависимости и запустите проект:

```bash
npm install
npm run dev
```

Vite покажет локальный адрес, обычно `http://localhost:5173`.

## Другие команды

```bash
npm run build    # production-сборка в папке dist
npm run preview  # локальный просмотр production-сборки
```

## Структура

- `src/App.jsx` — собирает страницу из компонентов.
- `src/components` — отдельные части страницы: шапка, секции и подвал.
- `src/data/siteData.js` — списки, пути к изображениям и контактные данные.
- `src/styles.css` — стили и адаптивные правила.
- `public/Image` и `public/fonts` — локальная копия графики и шрифтов для React-версии.

Главное отличие от старой версии: повторяющиеся элементы не копируются вручную в HTML.
Они хранятся в массивах в `siteData.js`, а React выводит их через `map()`. Мобильное меню
использует состояние `useState`, поэтому `document.querySelector` больше не нужен.

В старом сайте у иконок социальных сетей не было настоящих адресов. Чтобы их добавить,
заполните поля `href` у `socialLinks` в `src/data/siteData.js`.
